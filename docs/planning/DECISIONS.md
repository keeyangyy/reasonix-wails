## J. 优先级和已消除的误判

**已确认不属于冲突：**

- **3.73 单指针**：用户已明确在现有版本长期运行良好，不能因为推测某种 Beta 边界就认定现有设计有问题；在独立化阶段只迁移仓库/URL/签名并测试，不重写算法。
- **独立安装 vs 数据共享**：安装文件、注册表和私有进程状态分离，Studio 兼容的权威数据保持共享；两者是不同命名空间。真正的并发读写安全仍须测试，不能只凭方案判断已安全。
- **移除正式 CLI vs 保留核心**：桌面 Windows Terminal、Agent `slash_command`、MCP/插件、Go SDK、开发/Bench Runner 必须保留。
- **移除 Guard vs 保留事务更新**：Guard 的激活职责先由新激活器接替，`installlayout` 仍负责原子提交。
- **第一阶段不重构前端 vs 长期必须重构**：先稳定发行边界并建立测试；第二阶段解决状态和渲染复杂度。

**正式发行前仍需要真实验证/授权**：旧 Minisign 私钥控制权与操作规范；产品名和原图标公开再使用权；真实 Studio 数据 schema/并发；Windows 安装器卸载作用域；新仓库的 Secrets 与 Release 发布权限。它们可以在相应里程碑解决，不必阻塞 M0 的只读审计。
